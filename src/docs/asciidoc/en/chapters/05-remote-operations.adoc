=== Pulling with bookmark/phase sync

`fetch()` does everything `pull()` does, plus atomically synchronizes bookmarks and phases with
the remote.

[source,java]
----
include::{examplesdir}/RemoteOperationExamples.java[tag=fetch-changes]
----

IMPORTANT: Neither `pull()` nor `fetch()` touches the working copy -- both only update the local
repository's **store**. Always follow either one with `update()` (see <<branches-bookmarks>>) to
actually check the newly-fetched tip out.
