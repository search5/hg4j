=== 북마크/phase 동기화까지 함께 풀하기

`fetch()`는 `pull()`이 하는 일을 모두 하면서, 북마크와 phase까지 원격과 원자적으로
동기화합니다.

[source,java]
----
include::{examplesdir}/RemoteOperationExamples.java[tag=fetch-changes]
----

IMPORTANT: `pull()`과 `fetch()`는 작업 디렉터리를 건드리지 않고 로컬 저장소의 **store**만
갱신합니다. 새로 받은 tip을 실제로 체크아웃하려면 뒤이어 `update()`(<<branches-bookmarks>>
참고)를 반드시 호출해야 합니다.
