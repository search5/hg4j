== 변경사항 되돌리기 & 태깅

=== 파일 제거하기

[source,java]
----
include::{examplesdir}/HousekeepingExamples.java[tag=remove-files]
----

`remove()`는 추적을 해제함과 **동시에** 디스크에서 파일을 삭제합니다 -- 순수 `hg remove`와
동일합니다.

=== 파일 되돌리기 (revert)

[source,java]
----
include::{examplesdir}/HousekeepingExamples.java[tag=revert-files]
----

현재 수정된 상태인 파일은 덮어쓰기 전에 되돌리기 이전 내용이 `<file>.orig`로 백업됩니다 --
이미 클린한 파일은, 되돌릴 리비전의 내용이 디스크상의 내용과 다르더라도 백업이 생기지
않습니다.

=== 리비전에 태그 달기

[source,java]
----
include::{examplesdir}/HousekeepingExamples.java[tag=tag-a-revision]
----

일반 태그는 버전 관리되는 `.hgtags` 파일에 기록되고 자동으로 커밋됩니다. **로컬** 태그
(`setLocal(true)`)는 대신 `.hg/localtags`에 기록되며 절대 커밋되지 않습니다.

=== 전체 태그 목록 조회하기

[source,java]
----
include::{examplesdir}/HousekeepingExamples.java[tag=list-tags]
----

`tags()`는 `.hgtags`(커밋된 태그)와 `.hg/localtags`(로컬 태그)를 모두 합쳐서 반환하며,
`Tag#isLocal()`로 어느 쪽인지 구분할 수 있습니다.
