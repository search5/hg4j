=== 북마크/phase 동기화까지 함께 풀하기

`fetch()`는 `pull()`이 하는 모든 일에 더해, 원격과 북마크·phase까지 원자적으로 동기화합니다.

[source,java]
----
include::{examplesdir}/RemoteOperationExamples.java[tag=fetch-changes]
----

IMPORTANT: `pull()`과 `fetch()` 둘 다 작업 디렉터리는 건드리지 않습니다 -- 둘 다 로컬 저장소의
**store**만 갱신합니다. 새로 받은 tip을 실제로 체크아웃하려면 반드시 `update()`(<<branches-bookmarks>>
참고)를 뒤따라 호출하세요.
