== Getting Started

=== Adding the dependency

[source,groovy]
.build.gradle
----
dependencies {
    implementation 'io.github.search5.hg4j:hg4j:1.0.0'
}
----

`hg4j` targets Java 21. If you want to use `hg4j` as a Gradle SCM plugin instead of (or in
addition to) a plain library dependency, see the "Gradle Plugin Usage" section of the project
README.
