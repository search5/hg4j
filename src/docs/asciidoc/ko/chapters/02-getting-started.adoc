== 시작하기 (Getting Started)

=== 의존성 추가

[source,groovy]
.build.gradle
----
dependencies {
    implementation 'io.github.search5.hg4j:hg4j:1.0.1'
}
----

`hg4j`는 Java 21을 대상으로 합니다. 라이브러리 의존성 대신, 또는 의존성과 별개로 Gradle SCM
플러그인 형태로 `hg4j`를 쓰려면 프로젝트 README의 "Gradle Plugin Usage" 절을 참고하세요.

나머지 커맨드는 모두 이 인스턴스에서 호출합니다.
