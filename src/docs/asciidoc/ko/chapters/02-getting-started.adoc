== 시작하기 (Getting Started)

=== 의존성 추가

[source,groovy]
.build.gradle
----
dependencies {
    implementation 'io.github.search5.hg4j:hg4j:1.0.0'
}
----

`hg4j`는 Java 21을 대상으로 합니다. 라이브러리 의존성이 아니라(또는 그와 별개로) Gradle SCM
플러그인으로 `hg4j`를 쓰고 싶다면, 프로젝트 README의 "Gradle Plugin Usage" 절을 참고하세요.

파사드 인스턴스를 얻습니다.
